#Image Playground

Demo project to handle and manipulate images in a web environment. You can upload images, modify them, and test out with features like image cropping, resizing, and filters.

## Features
- **Dropzone** Easily drag and drop images for quick upload.
- **Inage Filters** Apply different filters like grayscale, sepia, and blur.
- **Resizing** Adjust the image dimensions as needed.
- **Cropping+* Select and crop specific areas of an image.

## Examples See [demo](https://lt123345.github.io/image-playground/).

## Installation
To run this project locally, clone the repository and install dependencies:

``b
git clone https://github.com/lt123345/image-playground.git
cd image-playground
npm install
```

```npm start
```
